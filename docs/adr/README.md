# Architecture Decision Records

This directory contains architectural decisions for the Stats App project.

## Active ADRs

| ADR | Title | Status |
|-----|-------|--------|
| 001 | Adopt monorepo with three deployable processes | Accepted |
| 002 | FastAPI owns the statistical domain and versioned API | Accepted |
| 003 | PostgreSQL as system of record, Redis for ephemeral coordination | Accepted |
| 004 | Process ingestion and predictions via idempotent worker | Accepted |
| 005 | Deploy with coordinated version and expand-contract migrations | Accepted |
| 006 | Deterministic walk-forward backtesting and promotion policy | Accepted |
